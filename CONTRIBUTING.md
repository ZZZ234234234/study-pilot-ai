# Contributing

StudyPilot AI is an early-stage open-source project. Small, verifiable changes are welcome.

1. Describe the problem in an issue, without including private PDFs, secrets or session cookies.
2. Create a branch from `main` and keep the change focused.
3. Add regression tests for changes to document ownership, citations, scheduling and grading.
4. Run the commands in the README and include actual results in the pull request.
5. Explain any new environment variables or migration requirements.

Use TypeScript strict mode, React functional components, Ruff for Python and Prettier for frontend source. Keep model credentials on the server. Mark demo behavior explicitly and never present fixture output as live AI output.

Do not force-push other contributors' branches. Avoid adding paid services or changing public interfaces without discussing the trade-off first. New dependencies should have a clear purpose and a compatible license.

Reports may be written in Chinese or English. Screenshots are useful for UI problems, but redact personal information first.
