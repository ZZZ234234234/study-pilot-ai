# StudyPilot AI 1.0.0 · Windows 桌面版

下载 `StudyPilot-AI-1.0.0-Windows-x64-Setup.exe`，安装后通过桌面快捷方式打开。不需要单独安装 Node、Python、PostgreSQL，也不需要启动命令或购买服务器。

## 功能

- 默认中文，可在设置中切换英文。
- 本地 PDF 上传、阅读、缩放、全屏及可移动的 AI 助手。
- 在 API 接入界面配置自己的 DeepSeek 或智谱模型，在对话中选择模型。
- PDF 中英对照翻译、来源引用、术语设置和文本导出。
- 图片/PDF 格式转换、知识整理和复习工具。
- 安装器、桌面快捷方式和本地数据保存。

## 请先了解

- 首版面向 Windows x64，暂不提供 macOS、手机安装包。
- AI 问答和翻译需要联网、用户自己的有效 API Key 及服务商额度；软件不附送模型额度。
- UI 新增的模型配置用于问答和翻译，尚未接管所有知识点/测验生成。演示资料仍有明确标记，不能把演示回答当成真实模型输出。
- 不包含扫描 PDF 的 OCR，也不支持原排版的翻译 PDF 导出。
- 资料保存在本机用户目录，桌面版不会自动导入原浏览器工作空间。卸载默认保留数据。
- API Key 当前存放在本地数据库，未使用 Windows 凭据加密；请保护电脑和备份，不要分享数据目录。
- 首版未购买代码签名证书，Windows 可能显示未知发布者警告。请核对仓库及 SHA-256，不要关闭系统安全防护。

## 验证范围

发布工作流要求前端/后端测试、生产构建、Windows 安装、打包后服务启动、八页样例 PDF 处理/下载以及重启后的资料保留检查成功。尚未覆盖所有 Windows 设备、真实付费模型响应质量及全部人工视觉操作，请通过 Issues 报告问题。
