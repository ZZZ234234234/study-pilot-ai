# StudyPilot AI 1.1.0 · Windows 桌面版

下载 `StudyPilot-AI-1.1.0-Windows-x64-Setup.exe`，安装后通过桌面快捷方式打开。不需要单独安装 Node、Python、PostgreSQL，也不需要启动命令或购买服务器。

## 功能

- 默认中文，可在设置中切换英文。
- 本地 PDF 上传、阅读、缩放、全屏，以及半透明、可移动、可调整大小的 AI 助手。
- 在 API 接入界面配置 19 类主流云端、聚合平台与本地模型，在问答和翻译中选择具体连接。
- 中国大陆模型：DeepSeek、智谱 AI、通义千问、Kimi、MiniMax、百度千帆、腾讯混元、豆包 / 火山方舟。
- 国际模型：OpenAI、Anthropic Claude、Google Gemini、xAI Grok、Mistral AI。
- 聚合与本地模型：OpenRouter、SiliconFlow、GroqCloud、Together AI、Ollama、LM Studio。
- 按地区选择预置官方端点；支持的服务可读取账号可用模型列表，其余服务提供参考型号或准确 ID 输入。
- 云端服务拒绝任意自定义转发地址，本地服务只接受回环地址；Ollama 与 LM Studio 默认可不填 API Key。
- 模型能力检测分别验证连接、JSON 输出、请求内上下文记忆与临时示例学习。
- PDF 中英对照翻译、来源引用、术语设置和文本导出。
- 图片/PDF 格式转换、知识整理和复习工具。
- 安装器、桌面快捷方式和本地数据保存。
- 侧栏作者身份、应用内真伪核验与维权说明、SHA-256 文件指纹和 GitHub 构建来源证明。

## 请先了解

- 首版面向 Windows x64，暂不提供 macOS、手机安装包。
- AI 问答和翻译需要联网、用户自己的有效 API Key 及服务商额度；软件不附送模型额度。
- 能力检测会产生一次小型模型请求；“上下文记忆 / 临时示例学习”不等于模型会永久训练。本版本不实现跨对话长期记忆。
- 模型配置用于问答和翻译，尚未接管所有知识点/测验生成。演示资料仍有明确标记，不能把演示回答当成真实模型输出。
- 不包含扫描 PDF 的 OCR，也不支持原排版的翻译 PDF 导出。
- 资料保存在本机用户目录，桌面版不会自动导入原浏览器工作空间。卸载默认保留数据。
- API Key 当前存放在本地数据库，未使用 Windows 凭据加密；应用不会把密钥写入 `.env`、浏览器持久存储或 Git。请保护电脑和备份，不要分享数据目录。
- 当前未购买代码签名证书，Windows 可能显示未知发布者警告。请核对官方仓库、SHA-256 与 GitHub 构建证明，不要关闭系统安全防护。

## 验证范围

发布工作流要求 211 项前端/后端/API 自动化检查、生产构建、Windows 安装、打包后服务启动、八页样例 PDF 处理/下载以及重启后的资料保留检查成功。19 类服务商的协议检查使用模拟 HTTP，不消耗真实模型额度；尚未覆盖所有 Windows 设备、真实付费模型响应质量及全部人工视觉操作，请通过 Issues 报告问题。
